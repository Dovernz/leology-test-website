# LearnHub — Meta Ads & Pixel Practice Website

Static e-learning website for practicing:

- Meta Pixel
- PageView
- ViewContent
- AddToCart
- InitiateCheckout
- Purchase
- Meta Ads funnel analysis

## Pages

- `index.html` — homepage / course listing
- `course.html` — course detail
- `checkout.html` — fake checkout
- `success.html` — fake purchase confirmation

## Setup

1. Deploy this repository with GitHub Pages.
2. Create a Meta Pixel.
3. Open `script.js`.
4. Replace `YOUR_PIXEL_ID` with the Pixel ID.
5. Commit the change.
6. Test the events in Meta Events Manager.

This is a simulation website. No real payments are processed.
